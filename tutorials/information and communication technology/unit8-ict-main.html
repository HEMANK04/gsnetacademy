ICT का अर्थ

Information and Communication Technology (ICT) refers to technologies used for collecting, processing, storing, retrieving and communicating information.

सूचना एवं संचार प्रौद्योगिकी उन technologies का समूह है जिनका उपयोग information को collect, process, store, retrieve और transmit करने के लिए किया जाता है।

ICT = Information Processing + Digital Storage + Communication Network

ICT के Components: Computer hardware, Software, Internet and networks, Telecommunication, Audio-video technology, Digital platforms, Cloud services, Database systems, Mobile communication, Artificial Intelligence

Educational Example: जब teacher Google Meet पर live class लेता है, LMS पर notes upload करता है और online quiz से assessment करता है, तो वह ICT-enabled teaching कर रहा है।

Computer System: Basic Concepts

Hardware: Physical components of a computer that can be seen or touched. Examples: Keyboard, monitor, CPU, printer, hard disk.

Software: Instructions or programs that direct a computer to perform tasks.

Types of Software:

  • System Software: Operating system, device drivers
  • Application Software: Word processor, browser, spreadsheet
  • Utility Software: Antivirus, backup, compression tools

Example: Windows/Linux → System software; MS Word → Application software; Antivirus → Utility software

5

Input and Output Devices

Input Devices: Data को computer में enter करते हैं। Keyboard, Mouse, Scanner, Microphone, Webcam, Barcode reader, OCR, OMR, MICR, Touchscreen

Output Devices: Processed information प्रस्तुत करते हैं। Monitor, Printer, Speaker, Projector, Plotter

Important Devices:

  • OCR: Printed characters को editable digital text में बदलता है
  • OMR: Shaded marks/bubbles पढ़ता है
  • MICR: Bank cheques पर magnetic-ink characters पढ़ता है
  • Barcode reader: Product code scan करता है
  • Biometric scanner: Fingerprint/iris जैसी biological identity पढ़ता है

Exam Trap: OMR handwritten essay नहीं पढ़ता। OCR shaded circles identify करने का primary device नहीं है। MICR का प्रमुख उपयोग banking में होता है।

6

Memory and Storage

Primary Memory: CPU द्वारा directly accessible memory.

  • RAM: Volatile memory, Temporary storage, Power बंद होने पर data lost, Read and write possible
  • ROM: Non-volatile memory, Permanent instructions, Power बंद होने पर data retained
  • Cache Memory: Very fast memory, CPU और main memory के बीच, Frequently used data/instructions रखती है

Secondary Storage: HDD, SSD, Pen drive, Memory card, CD/DVD, Magnetic tape

Memory Hierarchy: Registers → Cache → RAM → SSD/HDD → Optical/Tape

ऊपर से नीचे जाने पर: Speed decreases, Capacity increases, Cost per unit generally decreases

7

Units of Digital Storage

1 Byte = 8 bits

Traditional binary convention में: 1 KB = 1024 Bytes, 1 MB = 1024 KB, 1 GB = 1024 MB, 1 TB = 1024 GB

Order: Bit → Nibble (4 bits) → Byte (8 bits) → KB → MB → GB → TB → PB

Exam Trap: Lowercase b means bit and uppercase B means byte. Mbps = megabits per second; MBps = megabytes per second.

Types of Computer Networks

  • PAN - Personal Area Network: एक व्यक्ति के आसपास छोटी range का network। Example: Smartphone और wireless earbuds का Bluetooth connection।
  • LAN - Local Area Network: छोटे geographical area में network। Example: Computer laboratory or university department.
  • MAN - Metropolitan Area Network: City या metropolitan area तक फैला network।
  • WAN - Wide Area Network: Large geographical area covering countries or continents। Example: Internet.
PAN < LAN < MAN < WAN

Internet, Intranet and Extranet

  • Internet: A global public network of interconnected networks. Internet = Network of Networks
  • Intranet: Internet technologies पर आधारित private organisational network। Example: University का internal faculty portal.
  • Extranet: Controlled private network in which selected outsiders are also given authorised access। Example: University portal accessed by authorised vendors or collaborating institutions.

Internet vs World Wide Web

  • Internet: Physical and logical network infrastructure connecting devices worldwide.
  • World Wide Web: Internet पर उपलब्ध interlinked web pages और resources की service।
Internet is the infrastructure; WWW is a service running on it.

Other Internet Services: E-mail, FTP, VoIP, Video conferencing, Web browsing, Cloud services, Instant messaging

Exam Trap: Internet और WWW समान concepts नहीं हैं। WWW, Internet की services में से एक है।

E-mail

Electronic mail is a system for sending digital messages through a network.

Major Fields:

  • To: Primary recipient.
  • CC (Carbon Copy): Additional recipients visible to everyone.
  • BCC (Blind Carbon Copy): Additional recipients whose addresses other recipients cannot see.
  • Subject: Message का concise purpose.
  • Attachment: Message के साथ भेजी गई file.

E-mail Protocols: Sending → SMTP; Receiving/downloading → POP3; Server-based synchronisation → IMAP

POP3 vs IMAP: POP3 mail device पर download करता है (limited synchronisation, offline access useful). IMAP mail server पर manage करता है (multiple devices पर synchronisation, multi-device access useful). Example: यदि user mobile और laptop दोनों पर same inbox status देखना चाहता है, IMAP अधिक suitable है।

Audio Conferencing and Video Conferencing

Audio Conferencing: Participants केवल audio के माध्यम से communicate करते हैं।

Video Conferencing: Real-time audio and visual communication. Examples: Google Meet, Zoom, Microsoft Teams, Webex.

Essential Requirements: Computer/mobile device, Microphone, Speaker/headphones, Camera for video, Internet connection, Conferencing software/platform

Synchronous Communication: Participants same time पर interact करते हैं। Examples: Live Google Meet class, webinar, chat.

Asynchronous Communication: Participants का same time पर present होना आवश्यक नहीं। Examples: Recorded lecture, discussion forum, e-mail.

SynchronousAsynchronous
Real-timeTime-independent
Immediate feedbackDelayed feedback
Fixed scheduleFlexible access
Live classRecorded class

Advantages in Education: Remote access, Guest lectures, Collaboration, Immediate interaction, Reduced travel cost, Screen sharing and demonstration, Recording and revision

Limitations: Bandwidth problems, Digital divide, Screen fatigue, Reduced non-verbal cues, Privacy concerns, Technology anxiety, Distraction and multitasking

17

Bandwidth and Related Terms

  • Bandwidth: A communication channel की theoretical data-carrying capacity.
  • Data Transfer Rate: Actual data transferred per unit time.
  • Latency: Data को source से destination तक पहुँचने में लगने वाला delay.
  • Jitter: Packet delay में variation.

Video-conferencing Example: Low bandwidth → low video quality; High latency → response delay; High jitter → broken or irregular audio; Packet loss → missing audio/video segments

Exam Trap: High bandwidth alone does not guarantee perfect video conferencing; latency, jitter, congestion and device performance भी relevant हैं।

MOOCs

MOOC = Massive Open Online Course

  • Massive: Large number of learners
  • Open: Broad accessibility
  • Online: Internet-based delivery
  • Course: Organised learning experience

Major Characteristics: Learner-centric, Flexible access, Scalability, Multimedia content, Discussion and interaction, Assessment and certification possible, Self-paced or scheduled course possible, Credit and non-credit courses possible

Exam Trap: सभी MOOCs credit-based नहीं होते। MOOCs केवल SWAYAM पर उपलब्ध नहीं होते। Open access का अर्थ automatically high completion rate नहीं है। Course access free हो सकता है, लेकिन certification examination के लिए fee हो सकती है।

SWAYAM is India's online learning platform designed to facilitate access to courses across school and higher-education levels. The official platform describes access from Class 9 to postgraduate level, available to learners anywhere and anytime.

Core Principles: Access + Equity + Quality

Digital Divide

Digital divide means inequality in access to and effective use of digital technology.

डिजिटल विभाजन technology की उपलब्धता, affordability, skills और meaningful use में असमानता है।

Dimensions: Access divide, Affordability divide, Rural-urban divide, Gender divide, Language divide, Disability-related divide, Digital-literacy divide, Quality-of-connectivity divide, Usage and outcome divide

Example: Student के पास smartphone है, लेकिन stable Internet और digital literacy नहीं है। Device access होने के बावजूद meaningful access incomplete है।

Inclusive Measures: Accessible digital content, Captions and transcripts, Screen-reader compatibility, Regional-language content, Low-bandwidth resources, Offline downloads, Community digital centres, Digital-literacy training

ICT and Governance

E-Governance: Use of ICT by government to improve administration, service delivery, transparency, participation and accountability.

E-Governance = ICT + Public Services + Transparency + Accountability

Types of E-Governance Interaction:

  • G2C (Government to Citizen): Online certificates, tax services
  • G2G (Government to Government): Interdepartmental data exchange
  • G2B (Government to Business): E-tendering, online licences
  • G2E (Government to Employee): Payroll, service portal

Objectives: Faster services, Transparency, Reduced paperwork, Better record management, Citizen participation, Reduced transaction costs, Monitoring and accountability, Wider accessibility

Governance Models: Information Model (online information), Interaction Model (citizen feedback), Transaction Model (online payment/application), Transformation Model (integrated digital restructuring), Participation Model (online consultation)

Cybersecurity Basics

Malware: Malicious software designed to damage, disrupt or gain unauthorised access.

  • Virus: Host file/program से जुड़ता है
  • Worm: Network पर self-replicate कर सकता है
  • Trojan Horse: Legitimate software जैसा दिखाई देता है
  • Ransomware: Data encrypt करके ransom माँगता है
  • Spyware: Secretly information collect करता है
  • Adware: Unwanted advertisements
  • Rootkit: Malicious access/process छिपाता है
  • Logic bomb: Specific event पर activate होता है

Social Engineering Attacks:

  • Phishing: Fraudulent e-mail/message
  • Spear phishing: Targeted phishing
  • Smishing: SMS-based phishing
  • Vishing: Voice-call-based fraud
  • Pharming: User को fraudulent website पर redirect करना
  • Spoofing: False identity/address दिखाना

Protective Measures: Strong unique passwords, Multi-factor authentication, Updated software, Antivirus and firewall, Encryption, Regular backups, Secure Wi-Fi, Suspicious links से बचना, Role-based access control

Authentication Factors: Something you know (Password/PIN), Something you have (Phone/token/card), Something you are (Fingerprint/iris)

Exam Trap: Password + PIN necessarily two-factor authentication नहीं है, क्योंकि दोनों "something you know" category में हैं।

Common Exam Traps

  • Internet and WWW are not synonymous.
  • Internet is public; intranet is privately controlled.
  • Extranet allows selected external users.
  • SMTP sends e-mail; POP3/IMAP retrieve or access it.
  • BCC recipients are hidden from other recipients.
  • HTTPS adds encryption; it does not guarantee that every website is trustworthy.
  • RAM is volatile; ROM is non-volatile.
  • Google is a search engine; Chrome is a browser.
  • SWAYAM is an online course platform; SWAYAM PRABHA is DTH-based.
  • NDLI is a digital library; it is not the thesis-only repository.
  • Shodhganga contains theses; Shodhgangotri contains research synopses.
  • MOOCs may be credit or non-credit.
  • Blended learning is not merely using PowerPoint in a classroom.
  • Video conferencing is synchronous; recorded lecture is asynchronous.
  • Digital availability does not automatically ensure digital inclusion.
  • ICT governance includes alignment, security, accountability and resource use—not only hardware purchase.
  • Virus usually requires a host; worm can self-replicate over networks.
  • Phishing, smishing and vishing differ by communication medium.
