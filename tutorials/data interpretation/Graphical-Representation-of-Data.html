Graphical Representation — आलेखीय प्रस्तुति

Graphical Representation data को visual form (charts, graphs, diagrams) में present करना है।

Graph = Visual Data Presentation + Easy Interpretation + Quick Comparison

Advantages:

  • Easy to understand and interpret
  • Quick comparison of values
  • Shows trends and patterns clearly
  • Attractive and engaging
  • Simplifies complex data

Limitations:

  • May be misleading if not properly constructed
  • Approximate values (not precise)
  • Requires basic chart-reading skills
2

Bar Chart — दण्ड आरेख

Bar Chart rectangular bars (rectangles) का उपयोग करता है — bar की height या length value को दर्शाता है।

Bar Chart = Categories + Rectangular Bars + Height/Length = Value

Key Characteristics:

  • Bars have equal width
  • Bars are separated by gaps
  • Used for discrete/categorical data
  • Bars can be vertical or horizontal

Types of Bar Charts:

  • Simple Bar Chart: Single bar per category
  • Multiple/Grouped Bar Chart: Multiple bars per category
  • Stacked/Component Bar Chart: Bars divided into components
  • Percentage Bar Chart: Stacked bars showing percentages
  • Deviation Bar Chart: Bars above/below a baseline

Examples:

  • Department-wise enrollment
  • State-wise literacy rate
  • Year-wise sales comparison
  • Male-Female distribution

Histogram — आयतचित्र

Histogram continuous frequency distribution को दिखाने के लिए उपयोग किया जाता है।

Histogram = Continuous Data + Adjacent Rectangles + Area = Frequency

Key Characteristics:

  • Rectangles are adjacent (no gaps between bars)
  • Used for continuous data
  • X-axis shows class intervals
  • Area of rectangle represents frequency
  • Used for frequency distribution display

Examples:

  • Marks distribution of students
  • Age distribution of population
  • Height/Weight distribution
  • Any grouped frequency data

Unequal Class Intervals:

  • When class widths are unequal, use Frequency Density
Frequency Density = Frequency / Class Width

Pie Chart — वृत्त आरेख

Pie Chart एक circle (pie) को sectors में विभाजित करता है — प्रत्येक sector एक part of the whole को दिखाता है।

Pie Chart = Circle + Sectors + Angle = Percentage Share

Key Characteristics:

  • Shows part-to-whole relationship
  • Total = 100% (or 360°)
  • Each sector angle = (Value / Total) × 360°
  • Used for categorical data

Formulae:

  • Sector Angle: (Component Value / Total) × 360°
  • Percentage Share: (Component Value / Total) × 100

Quick Conversions:

  • 1% = 3.6°, 10% = 36°, 25% = 90°
  • 50% = 180°, 75% = 270°

Example: Total = 800, Science = 200 → 200/800 × 100 = 25% → 25% × 360° = 90°

Limitations:

  • Not good for many categories (overcrowding)
  • Difficult to compare similar-sized sectors
6

Line Chart — रेखा आरेख

Line Chart data points को lines से connect करता है — shows trends over time.

Line Chart = Points + Lines + Time = Trend

Key Characteristics:

  • Shows trends and patterns over time
  • Used for time-series data
  • Multiple lines for comparison
  • X-axis usually shows time

Interpretation:

  • Upward slope → Increase
  • Downward slope → Decrease
  • Horizontal line → No change
  • Steeper slope → Faster change

Examples:

  • Year-wise GDP growth
  • Monthly sales trend
  • Annual pass percentage
  • Population growth over years

Exam Trap: Steepness depends on the scale of axes — truncated or unequal axes may exaggerate change.

Table Chart — सारणी आरेख

Table Chart data को rows और columns में present करता है — shows exact numerical values.

Table Chart = Rows + Columns + Exact Values

Key Characteristics:

  • Shows precise numbers
  • Multiple variables can be shown together
  • Easy to calculate ratios, percentages, averages
  • Rows and columns with clear headings

Advantages:

  • Precise values available
  • Comparisons easy
  • All data in one place

Limitations:

  • Trend less immediately visible than in a line chart
  • Can be overwhelming with too much data

Example:

Common Exam Traps — सामान्य परीक्षा जाल

  • Trap 1: Bar chart has gaps; histogram does not → ✅ Correct distinction.
  • Trap 2: Histogram is for discrete data → ❌ Histogram is for continuous data.
  • Trap 3: Bar chart = continuous data → ❌ Bar chart is for discrete/categorical data.
  • Trap 4: Pie chart sector angles = percentage × 3.6 → ✅ 1% = 3.6°.
  • Trap 5: Line chart = part-to-whole → ❌ Line chart shows trends; pie chart shows part-to-whole.
  • Trap 6: Table chart = shows trends best → ❌ Table shows exact values; line chart shows trends.
  • Trap 7: In histogram, height of bar = frequency always → ❌ For unequal class intervals, frequency density is used.

Practice Questions — अभ्यास प्रश्न

Question 1

Which chart is best for comparing sales of different products?

  • A. Pie chart
  • B. Bar chart
  • C. Histogram
  • D. Line chart
Answer: B. Bar chart

Explanation: Bar chart is best for comparing categories.

Question 2

Which chart is used for continuous frequency distribution?

  • A. Bar chart
  • B. Histogram
  • C. Pie chart
  • D. Line chart
Answer: B. Histogram

Explanation: Histogram is used for continuous frequency distribution.

Question 3

In a pie chart, a sector represents 20% of the total. What is the sector angle?

  • A. 20°
  • B. 36°
  • C. 72°
  • D. 90°
Answer: C. 72°

Explanation: Angle = 20% × 360° = 72°.

Question 4

Which chart is most suitable for showing a trend over years?

  • A. Bar chart
  • B. Pie chart
  • C. Line chart
  • D. Histogram
Answer: C. Line chart

Explanation: Line chart shows trends over time.

Question 5

What is the key difference between a bar chart and a histogram?

  • A. Bar chart has gaps; histogram does not
  • B. Histogram has gaps; bar chart does not
  • C. Both have gaps
  • D. Neither has gaps
Answer: A. Bar chart has gaps; histogram does not

Explanation: Bar chart bars are separated by gaps; histogram bars are adjacent (no gaps).

Question 6

Total marks = 500. A student scored 150 marks in Science. What is the central angle in a pie chart?

  • A. 72°
  • B. 90°
  • C. 108°
  • D. 120°
Answer: C. 108°

Explanation: (150/500) × 360° = 0.3 × 360° = 108°.

One-Page Revision — एक पेज में पुनरावृत्ति

Bar Chart = Categories + Gaps | Histogram = Continuous + No Gaps
Pie Chart = Part-to-Whole | Line Chart = Trend | Table = Exact Values

Bar Chart:

  • Discrete data, gaps between bars, height = value
  • Types: Simple, Multiple, Stacked, Percentage

Histogram:

  • Continuous data, no gaps, area = frequency
  • Frequency Density = f / Class Width (for unequal intervals)

Pie Chart:

  • Part-to-whole, Angle = (Value/Total) × 360°
  • 1% = 3.6°, 25% = 90°, 50% = 180°

Line Chart:

  • Time trends, points connected by lines
  • Up = Increase, Down = Decrease, Flat = No change

Table Chart:

  • Rows + Columns + Exact values
  • Good for precise calculations

Exam Formula:

Chart → Data Type → Purpose → Key Feature
