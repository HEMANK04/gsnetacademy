Arguments, Propositions & Reasoning

Complete tutorial: Argument and its structure, Premise & Conclusion, Argument vs Explanation, Proposition vs Sentence, Deductive Reasoning, Inductive Reasoning, Validity, Soundness, Strength & Cogency.

Meaning of Argument — तर्क का अर्थ

Argument statements (propositions) का एक set है जिसमें एक statement (conclusion) को दूसरी statements (premises) के support में प्रस्तुत किया जाता है।

Argument = Premises + Conclusion

Key Points:

  • Argument में कम-से-कम two statements होते हैं (at least one premise + one conclusion)
  • Argument का उद्देश्य conclusion को justify (सही साबित) करना है
  • Argument reasoning की process है

Example:

  • Premise 1: All humans are mortal.
  • Premise 2: Socrates is a human.
  • Conclusion: Therefore, Socrates is mortal.

NOT an Argument (Just a Statement):

  • "The sky is blue." — यह केवल एक statement है, argument नहीं (क्योंकि कोई premise नहीं है)।
2

Structure of Argument — तर्क की संरचना

Basic Structure:

Premise(s) → Conclusion

Components:

  • Premises — आधार/पूर्वपद: वे statements जो conclusion को support (समर्थन) करते हैं।
  • Conclusion — निष्कर्ष: वह statement जिसे premises से derive (प्राप्त) किया जाता है।
  • Inference — अनुमान: Premises से conclusion तक पहुँचने की logical process।

Indicator Words (Signal Words):

  • Premise Indicators: because, since, for, as, given that, in that, assuming that
  • Conclusion Indicators: therefore, thus, hence, so, consequently, accordingly, it follows that, we can conclude that

Example with Indicators:

  • "Since all teachers are educated (premise), and Mr. Sharma is a teacher (premise), therefore, Mr. Sharma is educated (conclusion)."
3

Premise & Conclusion — आधार एवं निष्कर्ष

  • Premise — आधार: वह statement जो evidence, reason या support प्रदान करता है।
  • Conclusion — निष्कर्ष: वह statement जो premises से logically follow करता है।

Identifying Premises and Conclusions:

  • Look for indicator words (because, since → premises; therefore, hence → conclusion)
  • Ask: "What is the main claim being made?" → Conclusion
  • Ask: "What evidence is being provided?" → Premises

Example:

  • "The roads are wet (premise). Therefore, it must have rained (conclusion)."
  • "It must have rained (conclusion) because the roads are wet (premise)."
4

Argument vs Explanation — तर्क vs व्याख्या

BasisArgumentExplanation
PurposeTo prove/justify a claimTo clarify/account for why something happened
DirectionPremises → Conclusion (unknown to known)Known phenomenon → Cause/Reason
AudienceSomeone who disagrees/doesn't believeSomeone who doesn't understand
Example"It rained because the forecast predicted it." (Proving)"The roads are wet because it rained." (Explaining)

Key Distinction:

  • Argument: "X is true because Y" — Y साबित करता है कि X true है।
  • Explanation: "X happened because Y" — Y बताता है कि X क्यों happened (X already accepted as true).

Example:

  • Argument: "The teacher must be competent because all students scored well." (Scoring well proves competency)
  • Explanation: "The students scored well because the teacher is competent." (Competency explains the score — score is already known)
5

Proposition vs Sentence — प्रस्ताव vs वाक्य

  • Proposition — प्रस्ताव: वह meaning/content जो एक declarative sentence व्यक्त करता है। यह true या false हो सकता है।
  • Sentence — वाक्य: वह grammatical structure जिसके माध्यम से proposition व्यक्त किया जाता है।
Proposition = Meaning/Content | Sentence = Grammatical Expression

Key Differences:

  • Same proposition can be expressed by different sentences (different languages, different words).
  • Not all sentences express propositions (questions, commands, exclamations do NOT).
  • Propositions are truth-evaluable (can be true or false).

Example:

  • Same Proposition: "The sky is blue." / "आकाश नीला है।" (same meaning, different sentences)
  • Not a Proposition: "Where are you going?" (question — not true/false)
  • Not a Proposition: "Please close the door." (command — not true/false)
6

Types of Propositions — प्रस्तावों के प्रकार

  • Categorical Proposition — श्रेणीबद्ध प्रस्ताव: Two classes/categories के बीच relationship बताता है। (All S are P, Some S are P, etc.)
  • Conditional Proposition — सशर्त प्रस्ताव: "If...then..." statement. (If P, then Q)
  • Disjunctive Proposition — वियोजक प्रस्ताव: "Either...or..." statement. (Either P or Q)
  • Conjunctive Proposition — संयोजक प्रस्ताव: "And" statement. (P and Q)

Categorical Proposition Forms:

  • Universal Affirmative (A): All S are P (e.g., All humans are mortal)
  • Universal Negative (E): No S are P (e.g., No humans are perfect)
  • Particular Affirmative (I): Some S are P (e.g., Some students are intelligent)
  • Particular Negative (O): Some S are not P (e.g., Some students are not intelligent)
7

Deductive Reasoning — निगमनात्मक तर्क

Deductive = General → Specific | Conclusion is Certain

Key Points:

  • Moves from general premises to specific conclusion
  • If premises are true, conclusion must be true (certainty)
  • Argues from rules/principles to specific cases
  • Example: All humans are mortal → Socrates is human → Socrates is mortal

Evaluation Criteria:

  • Validity: If premises are true, conclusion must be true (structural correctness)
  • Soundness: Valid argument with true premises
8

Inductive Reasoning — आगमनात्मक तर्क

Inductive = Specific → General | Conclusion is Probable

Key Points:

  • Moves from specific observations to general conclusion
  • Conclusion is probable, not certain
  • Used in science, research, everyday reasoning
  • Example: Swan 1 is white, Swan 2 is white, Swan 3 is white → All swans are white (probable)

Evaluation Criteria:

  • Strength: How strongly the premises support the conclusion (degree of probability)
  • Cogency: Strong argument with true premises
9

Deductive vs Inductive — निगमनात्मक vs आगमनात्मक

BasisDeductiveInductive
DirectionGeneral → SpecificSpecific → General
CertaintyCertain (if valid)Probable
EvaluationValidity, SoundnessStrength, Cogency
ExampleAll men are mortal. Socrates is a man. → Socrates is mortal.Swan 1 white, Swan 2 white → All swans are white.
NatureTruth-preservingProbability-increasing
10

Validity — वैधता

Validity एक deductive argument की structural/logical property है।

Valid = If premises are true, conclusion MUST be true

Key Points:

  • Validity only applies to deductive arguments
  • Validity does NOT depend on actual truth of premises
  • A valid argument can have false premises
  • An invalid argument can have true premises and true conclusion

Examples:

  • Valid (True Premises): All men are mortal. Socrates is a man. → Socrates is mortal.
  • Valid (False Premises): All birds can fly. Penguins are birds. → Penguins can fly. (Valid structure, but false premise → unsound)
  • Invalid: All dogs are animals. Cats are animals. → Cats are dogs. (Structural flaw)
11

Soundness — सत्यता (साधुता)

Soundness एक deductive argument की अतिरिक्त property है।

Sound = Valid + All Premises are True

Key Points:

  • Soundness requires validity
  • Sound argument का conclusion definitely true होता है
  • An unsound argument can be: (a) invalid, OR (b) valid with at least one false premise

Examples:

  • Sound: All men are mortal. Socrates is a man. → Socrates is mortal. (Valid + true premises)
  • Unsound (Valid but false premise): All birds can fly. Penguins are birds. → Penguins can fly. (Valid structure, but premise false → unsound)
  • Unsound (Invalid): All dogs are animals. Cats are animals. → Cats are dogs. (Invalid → unsound)
12

Strength — बल/प्रबलता

Strength एक inductive argument की quality है।

Strong = Premises make the conclusion highly probable

Key Points:

  • Strength only applies to inductive arguments
  • Strength is a matter of degree (more or less strong)
  • Strong argument = premises provide strong support for conclusion
  • Weak argument = premises provide little support for conclusion

Examples:

  • Strong: 10,000 swans observed; all white → All swans are white. (Strong inductive support)
  • Weak: 2 swans observed; both white → All swans are white. (Weak inductive support)
  • Strong: 90% of students passed after using this method → This method helps students pass.
13

Cogency — सुसंगतता/युक्तियुक्तता

Cogency एक inductive argument की अतिरिक्त property है।

Cogent = Strong + All Premises are True

Key Points:

  • Cogency requires strength
  • Cogent argument का conclusion probably true होता है
  • Uncogent argument = (a) weak, OR (b) strong with at least one false premise

Examples:

  • Cogent: 90% of students passed with this method (based on reliable data) → This method is effective. (Strong + true premises)
  • Uncogent (Strong but false premise): Based on fabricated data showing 90% pass rate → This method is effective. (Strong structure, but false premise → uncogent)
  • Uncogent (Weak): 2 students passed with this method → This method is effective. (Weak → uncogent)

Evaluation Summary — मूल्यांकन सारांश

Argument TypeStructural CriteriaFull Criteria
DeductiveValidity (if premises true → conclusion must be true)Soundness (Valid + True premises)
InductiveStrength (premises make conclusion probable)Cogency (Strong + True premises)

Quick Memory Formula:

Deductive → Valid → Sound (with true premises)
Inductive → Strong → Cogent (with true premises)

Common Exam Traps — सामान्य परीक्षा जाल

  • Trap 1: Validity = true premises → ❌ Validity is about logical structure, not truth of premises.
  • Trap 2: Soundness = only validity → ❌ Soundness = validity + true premises.
  • Trap 3: Strength = truth of conclusion → ❌ Strength is about how well premises support the conclusion.
  • Trap 4: Cogency = only strength → ❌ Cogency = strength + true premises.
  • Trap 5: Argument and explanation are the same → ❌ Argument proves; explanation clarifies.
  • Trap 6: Proposition = sentence → ❌ Proposition is meaning; sentence is grammatical expression.
  • Trap 7: Inductive reasoning = certain → ❌ Inductive reasoning is probabilistic, not certain.

Practice Questions — अभ्यास प्रश्न

Question 1 (Argument Structure)

Identify the conclusion: "All students must pass the exam. Rahul is a student. Therefore, Rahul must pass the exam."

  • A. All students must pass the exam
  • B. Rahul is a student
  • C. Rahul must pass the exam
  • D. None of the above
Answer: C. Rahul must pass the exam

Explanation: "Therefore" indicates the conclusion. Premises: "All students must pass" and "Rahul is a student".

Question 2 (Argument vs Explanation)

"The ground is wet because it rained." This is an example of:

  • A. Argument
  • B. Explanation
  • C. Proposition
  • D. Sentence
Answer: B. Explanation

Explanation: "The ground is wet" is accepted as true; "it rained" explains why it is wet — this is an explanation, not an argument.

Question 3 (Proposition vs Sentence)

Which of the following is NOT a proposition?

  • A. The sky is blue
  • B. 2+2=4
  • C. Please close the door
  • D. All humans are mortal
Answer: C. Please close the door

Explanation: A command is not a proposition because it cannot be true or false. Propositions are declarative statements that can be true/false.

Question 4 (Deductive vs Inductive)

"Every swan I have seen is white. Therefore, all swans are white." This is an example of:

  • A. Deductive reasoning
  • B. Inductive reasoning
  • C. Validity
  • D. Soundness
Answer: B. Inductive reasoning

Explanation: It moves from specific observations (some swans) to a general conclusion (all swans) — inductive reasoning.

Question 5 (Validity)

An argument is valid if:

  • A. All premises are true
  • B. The conclusion is true
  • C. If premises are true, the conclusion must be true
  • D. The conclusion is probable
Answer: C. If premises are true, the conclusion must be true

Explanation: Validity is about logical structure — truth-preserving relationship from premises to conclusion.

Question 6 (Soundness)

A sound argument must be:

  • A. Valid
  • B. Have true premises
  • C. Both valid and have true premises
  • D. Strong
Answer: C. Both valid and have true premises

Explanation: Soundness = Validity + True premises.

Question 7 (Cogency)

A cogent argument is:

  • A. A valid deductive argument
  • B. A strong inductive argument with true premises
  • C. A weak inductive argument
  • D. An invalid deductive argument
Answer: B. A strong inductive argument with true premises

Explanation: Cogency = Strength + True premises (applies to inductive arguments).

One-Page Revision — एक पेज में पुनरावृत्ति

Argument = Premises → Conclusion

Key Concepts:

  • Premise: Evidence/support for conclusion
  • Conclusion: Claim being supported
  • Proposition: Meaning/content (true/false)
  • Sentence: Grammatical expression

Argument vs Explanation:

  • Argument → Proves/justifies
  • Explanation → Clarifies/accounts for

Deductive Reasoning:

  • General → Specific, Certain
  • Evaluation: Validity, Soundness

Inductive Reasoning:

  • Specific → General, Probable
  • Evaluation: Strength, Cogency

Evaluation Criteria:

  • Validity: Deductive (if premises true → conclusion must be true)
  • Soundness: Deductive (Valid + True premises)
  • Strength: Inductive (premises support conclusion strongly)
  • Cogency: Inductive (Strong + True premises)

Exam Formula:

Valid ≠ True | Sound = Valid + True | Strong ≠ Cogent | Cogent = Strong + True
