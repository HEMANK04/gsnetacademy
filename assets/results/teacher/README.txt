Teacher & Assistant Professor result posters go in this folder.

Name them with a number in front so the order stays predictable:
  01-name.jpg, 02-name.jpg, 03-name.jpg ...

jpg / jpeg / png / webp all work. Drop a file in, save, and it shows up on the
homepage on its own - no code change needed. While this folder has no images,
the "Teacher & Assistant Professor" tab stays hidden.
